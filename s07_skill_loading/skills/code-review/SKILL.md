# Code Review Skill

对给定代码或文件进行系统性审查，输出结构化的审查报告。

## 审查维度

1. **正确性** — 逻辑错误、边界条件、空值处理
2. **安全性** — SQL 注入、XSS、路径穿越、敏感数据泄露
3. **性能** — 时间复杂度、不必要的重复计算、大循环内的 I/O
4. **可维护性** — 函数长度、命名清晰度、重复代码（DRY 违反）
5. **类型安全** — TypeScript any 滥用、隐式类型转换

## 输出格式

```markdown
## 审查摘要
- 严重问题：N 个
- 建议改进：M 个

## 严重问题
1. [文件:行号] 问题描述 — 修复建议

## 建议改进
1. [文件:行号] 建议描述

## 总体评价
一段话总结代码质量。
```

## 使用示例

用户说"帮我看看这个文件有没有问题"时，使用此技能对指定文件或目录执行全面审查。
